## แก้แล้ว

ทุกรายการด้านบนแก้ครบ → ทุกไฟล์ตอนนี้ ✓ pass

- Sidebar: `inert` เมื่อปิดและจอ < 1024px (matchMedia), focus trap เฉพาะมือถือ, ขยายถึง lg → `onClose()`
- Header: ปิดเมนูโปรไฟล์ด้วย `pointerdown` นอกเมนู
- tabs.tsx: `ErrorText` รับ `id`, file input ผูก `aria-describedby`, ล้าง error เมื่อเลือกไฟล์
- ActionDialog: `dirty` รวมวันที่/ค่าที่เปลี่ยนจากค่าเริ่มต้น, เพิ่ม `autoComplete="off"`
- assess: progress ใช้ `scaleX` (transform) แทน width, ConfirmDialog ใหม่ใช้ `useFocusTrap` + Esc, ปุ่มระดับ/หมวดเป็นปุ่ม `aria-pressed`/`aria-current`, `aria-hidden` ไอคอน, name/autoComplete, `…` ใน placeholder, summary card `md:sticky md:top-20`
- รายละเอียดคำขอ: tab roving (ลูกศรซ้าย/ขวา + `tabIndex`), hover บนปุ่ม chip/tab
- globals.css: `scroll-padding-top`, `overscroll-behavior: none` (pointer: fine), tabular-nums ในตาราง
- หัวข้อ: Certificate h1→h2, HomeTasks h3→h2, login h2→p
- อื่น ๆ: aria-hidden ไอคอน, input search ของ /certificates, `th` มี sr-only, curly quotes, aria-describedby ใน DocsStep

## ข้ามตาม spec

- Title Case ของหัวข้อ/ปุ่ม (UI เป็นภาษาไทย)
- รูป/วิดีโอ (ไม่มี `<img>`/`<video>`; แนบรูปเก็บแค่ชื่อไฟล์)
- virtualization (รายการ PoC < 50 แถว)
- `beforeunload` ทั้งหน้า (ฟอร์มยื่นคำขอบันทึกร่างอัตโนมัติ; ActionDialog ถามก่อนปิด)
- dark mode / `color-scheme`
